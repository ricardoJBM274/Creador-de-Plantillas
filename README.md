# 📱 Generador de Capturas para Play Store

Una herramienta web profesional y estática para diseñar, previsualizar y exportar assets gráficos para la Google Play Console. Ideal para desarrolladores móviles que necesitan generar mockups de alta calidad sin depender de software de pago.

---

## ✨ Características Principales

* **📱 Soporte Multidispositivo:** Genera banners para Teléfono (1080x1920) y Tablet de 10" (1600x2560).
* **🎨 Fondos Personalizables:** Soporte para colores sólidos y degradados lineales.
* **📐 Posicionamiento Avanzado:** Control total sobre la escala, posición (X/Y) y rotación (grados) tanto del texto como de los dispositivos.
* **📱📱 Modo Dual:** Capacidad de renderizar dos dispositivos simultáneos con profundidad y perspectivas independientes.
* **💾 Sistema de Proyectos:** Exporta e importa tus diseños completos en formato `.json` para no perder tu progreso.
* **🛠️ Herramientas Extra:** Incluye generadores con recorte automático para el **Icono de la App (512x512)** y el **Gráfico de Funciones (1024x500)** exigidos por Google Play.

---

## 🚀 Cómo usarlo

Dado que es un proyecto puramente frontend (HTML, CSS, Vanilla JS), no requiere instalación ni dependencias de Node.js.

1. Clona este repositorio:
   ```bash
   git clone [https://github.com/tu-usuario/generador-capturas.git](https://github.com/tu-usuario/generador-capturas.git)

2. Abre el archivo index.html en tu navegador web preferido.

¡Empieza a diseñar! Selecciona un dispositivo, sube tu captura de pantalla y ajusta los controles en el panel lateral.

Exporta tu diseño en formato PNG directamente a tu equipo.

(Nota: Si usas VS Code, puedes usar la extensión "Live Server" para una experiencia de desarrollo más fluida).
